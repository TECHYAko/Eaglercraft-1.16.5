Eaglercraft 1.16.5

u3

A port of the Minecraft 1.16.5 Java client to the browser, compiled to WebAssembly.

What this is

The decompiled 1.16.5 client, rebuilt to run on the EaglercraftX platform layer and compiled to WASM-GC with TeaVM. The JVM APIs the game expects — threads, NIO, AWT, LWJGL — don't exist in a browser, so each one is re-implemented against WebGL, Web Audio, WebSockets and IndexedDB behind a platform abstraction.

It runs fully client-side. No install, no plugins, no server round-trip for singleplayer.

Engineering notes

Single-threaded runtime
TeaVM has no real threads, so createNamedService() returns a direct executor — chunk generation, lighting and mesh building all run on one thread and must cooperatively yield or the tab freezes.
Integrated server in a Web Worker
Singleplayer runs a real server in a worker, talking to the client over postMessage IPC instead of a socket.
Fixed-function GL emulation
1.16's renderer targets modern GL. The platform layer emulates it over WebGL with a shader permutation cache keyed on pipeline state bits.
Allocation pressure
WASM-GC has no generational nursery, so per-frame garbage that a JVM would absorb becomes visible stutter. Much of the optimization work is removing allocations from the chunk meshing and visibility paths.
